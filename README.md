# Trabajo Final Integrador - Desarrollo en Angular

## Descripción breve del proyecto
Este proyecto es una aplicación de gestión desarrollada en Angular, correspondiente al Trabajo Final Integrador. Su objetivo principal es gestionar el estado de productos y usuarios. La aplicación implementa una estructura en módulos, manejo de rutas con *lazy loading* para Productos y Usuarios, vistas de detalle independientes y un *sidebar* permanente que permite navegar fluidamente entre las secciones principales (Inicio, Productos y Usuarios).

## Instrucciones para clonar, instalar dependencias y ejecutar

1. **Clonar el repositorio:**
   ```bash
   git clone <URL_DEL_REPOSITORIO>
   cd trabajo-final
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Ejecutar la aplicación:**
   ```bash
   ng serve
   ```
   Luego, abre tu navegador y dirígete a `http://localhost:4200/`.
